Projects

Discord BE Clone

Main Repo Front-end

After I found out that Discord uses Elixir, I decided to give a shot at trying to create a live chatting service with Phoenix that takes advantage of Elixir's concurrency design principle.

The heart of the project was the back-end service that allowed users to sign up for accounts that they can use to create and join chatrooms with. I utilized Elixir's DynamicSupervisors and Registries to host rooms on their own processes, which meant if one room were to crash, the service would be online for other users as it rebooted. Lastly, I used Phoenix's sockets to push and receive real-time data to all the clients connected to a room.

I also quickly built a front-end client in React and TailwindCSS to be able to demo the project. Links to the repos are next to the title.

Finance Tracker

Back-end Front-end

Soon after learning Elixir, I wanted to finally try building a service to move my finance tracking from just a boring excel sheet to a web app.

I used Elixir and Phoenix to build the back-end of the app that stores expense data. It also exposed some endpoints for the front-end to fetch aggregated data for the summary pages. This was my first time starting a Phoenix project from scratch, so I learned a lot about setting up the DB, creating the schemas, using phoenix gen functions, setting up the plugs. Overall, I was able to gain a better understanding of how Elixir and Phoenix works.

I built the front-end in React with the JoyUI component library for the styling. At this point I've already had 2 years of front-end experience and ~12 months of experience building admin pages, so this was a nice refresher from the back-end work that I was working on. I did get a better grasp on handling forms.

I also built a python script to scrape my PDF bank statements to convert into CSV data to upload into web app.
